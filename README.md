# AI Marketing Studio

Laboratorio de agentes para marketing audiovisual: fotografía, Reels y videos explicativos.

## Objetivo
Entender la orquestación de un agente maestro, especialistas, skills y herramientas. La primera versión es un simulador HTML, sin gasto de créditos ni integraciones externas.

## Componentes
- `CLAUDE.md`: reglas del agente maestro.
- `.claude/agents/`: agentes especialistas.
- `.claude/skills/`: procedimientos.
- `preview.html`: simulador animado.

**Importante:** no subir claves API ni credenciales a este repositorio público.
