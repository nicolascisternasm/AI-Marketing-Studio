# Edición fotográfica
1. Analiza iluminación, color, composición y encuadre.
2. Define elementos que no pueden cambiar.
3. Redacta prompt de edición para la herramienta disponible.
4. Verifica fidelidad y naturalidad del resultado.
5. Solicita aprobación para cambios sustanciales.
