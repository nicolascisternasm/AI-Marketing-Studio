# reels-flowpedido

Carpeta de Reels producidos para **@flowpedido** — plataforma SaaS para pymes gastronómicas en Chile.

## Estructura

```
reels-flowpedido/
├── educacion/       # Consejos y educación para dueños de local
├── demos/           # Demos del panel y funcionalidades
├── prueba-social/   # Testimonios y casos reales
└── cultura/         # Detrás de escena del equipo
```

## Workflow

1. Crear guion con `/flowpedido-reels` en Claude Code
2. Grabar material (pantallas del panel, local, etc.)
3. Editar en ChatCut
4. Subir video a la carpeta correspondiente
5. Programar en Metricool → Brand FlowPedido → @flowpedido
