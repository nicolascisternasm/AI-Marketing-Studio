# Reels MAMKAM

Videos finales (1080×1920, MP4) listos para Instagram. Un archivo por reel, ordenados por mes y con la fecha de creación al inicio del nombre: `AAAA-MM-DD_producto_tema.mp4`.

Los enlaces "raw" son los que se usan en Metricool para programar (el repositorio es público).
